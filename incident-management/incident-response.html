🚨 Incident Response Flow

SRE — Like you're 5, then like you're an engineer
🧒 LIKE YOU'RE 5
Imagine you're in a school kitchen and the fire alarm goes off. Here's what you do:

🔔 "Is it real?" — First, check if it's a drill or actual smoke. You look around: yep, something's burning in the oven.

🔍 "How bad?" — Is the whole kitchen on fire (SEV1) or just one pan (SEV2)? If just one pan, grab the extinguisher. If whole kitchen, evacuate.

🪣 "Put out the fire FIRST" — Don't try to figure out WHY the fire started while it's still burning. Pull the pan out, cut the gas. Fix the symptom, not the cause — for now.

✅ "All clear" — Fire's out. Everyone can breathe. Tell the principal "we're safe now."

📝 "How did this happen?" — After everyone's calm, sit down and figure out: was it the new recipe? Did someone leave the oven on? Fix the system, not the cook.

The golden rule: 🚒 Put out the fire FIRST. Figure out the cause AFTER.
↓ Now let's call it what it really is ↓
🔧 FOR THE ENGINEER
🔔

1. Detection

Alert fires via Prometheus AlertManager, Grafana, or PagerDuty.

First responder acknowledges within SLA (e.g., 5 min for SEV1).

Noise reduction: Use alert thresholds with hysteresis, not raw thresholds.

🔍

2. Triage

Assess severity by impact:

SEV1: Users impacted, revenue down
SEV2: Degraded experience
SEV3: Cosmetic/internal

Declare incident. Open bridge. Notify stakeholders.

🛠️

3. Mitigation

Fix the symptom FIRST:
• Rollback the last deploy
• Scale up replicas
• Redirect traffic to healthy AZ
• Feature flag toggle off

🚫 Do NOT debug root cause while service is down.

✅

4. Resolution

Service healthy. Monitoring back to baseline.

• De-escalate incident
• Close the bridge
• Notify "all clear"
• Silent alarms for N hours if needed

📖

5. Postmortem

Blameless postmortem within 48h.

Structure: Timeline → Root cause → Impact → Action items.

Each action item gets an owner + deadline. Fix the system, not the person.

🎯

Error Budgets & MTTR

Error Budget: 99.9% SLO = 8.76h downtime/year. Deploy risky changes when you have budget remaining.

MTTR: Mean Time To Resolve. Every minute shaved off MTTR increases your error budget.

🚒

Micro-action: Does your team have a documented incident response runbook? If yes, open it and check if it's up to date. If no, start one — just the 5 stages above is enough for a first draft.
